# IBRA PENGUINS — بطاريق إبرا

لعبة ألغاز للبطاريق بدقة **1920×1080** مستوحاة من ألعاب الطفولة القديمة.
البطاريق تمشي وحدها، وأنت تسحب الأدوات إلى المرحلة حتى توصل العدد المطلوب منها لباب الخروج.

**تصميم وتطوير: إبراهيم الخزرجي** · [t.me/ibraprogram](https://t.me/ibraprogram) · [TikTok @ibraprogram](https://www.tiktok.com/@ibraprogram)
</div>

## المحتوى

- **25 مرحلة** في 5 مناطق: بركة البطاريق ❄️، غابة المايا 🌴، سهول الأسود 🏜️، كهوف الخفافيش 🦇، تحدي الليل 🌙
- **القصة:** صديق البطاريق «ثلجي» ضايع داخل حديقة الحيوانات، ونلقاه بنهاية كهوف الخفافيش
- **5 أدوات:** مدفع (بزاوية وقوة تختارها)، نابض، جسر خشب، مروحة رفع، لافتة اتجاه
- عملات تُجمع، **3 نجوم** لكل مرحلة، وقت مطلوب للتغلب عليه، تلميح يبيّن مكان الأداة
- 4 ملفات لاعبين، خريطة الحديقة، **متجر هدايا** (قبعات وأزياء للبطاريق)، موسيقى ومؤثرات مولّدة بالكود
- **محرر مراحل** داخل اللعبة + تحميل مراحل إضافية من ملفات JSON
- عربي / English، ملء الشاشة (F11)

## التحكم

| الفعل | الطريقة |
|---|---|
| وضع أداة | اسحبها من الشريط السفلي إلى المرحلة |
| تدوير | كلك يمين (على الأداة أو أثناء السحب) أو `R` |
| قوة المدفع | عجلة الماوس فوق المدفع، أو زر ⚡ |
| تحريك / إزالة | اسحب الأداة الموجودة / `Delete` أو زر ✖ |
| إيقاف / سرعة | `Space` / `1` `2` `3` |
| تلميح | `H` |
| القائمة | `Esc` |

## التشغيل والبناء

```bash
npm install
npm start          # تشغيل اللعبة
npm test           # يتأكد إن كل مرحلة تنحل وما تنحل بدون أدوات
npm run dist       # يبني المثبّت: dist/IBRA-PENGUINS-Setup-x.y.z.exe
```

بناء المثبّت تلقائياً على GitHub: سوِّ tag مثل `v1.0.1` وادفعه — الـ workflow يبني الـ EXE ويرفقه بالـ Release.

## إضافة مراحل (قابلة للتطوير)

1. **من داخل اللعبة:** «محرر المراحل» ← ارسم الأرض، ضع البداية والخروج، حدد الأدوات، ثم «جرّب». الحل الذي تنجح به يُحفظ تلقائياً كتلميح. مراحلك تظهر بالخريطة تحت «مراحلي».
2. **ملفات JSON:** ضع أي ملف `.json` في مجلد `levels` جنب ملف اللعبة (أو `%APPDATA%/IBRA PENGUINS/levels`) — يظهر بالخريطة كحزمة مراحل إضافية. شوف `levels/example-pack.json` و[docs/LEVELS.md](docs/LEVELS.md).
3. **بالكود:** كل منطقة ملف مستقل في `src/levels/worldN.js`. لإضافة منطقة جديدة أضف ملفاً وسجّله في `src/levels/index.js`.

## هيكل المشروع

```
src/engine/    محرك اللعبة (بدون رسوم — يشتغل حتى في node للاختبار)
  terrain.js   أرض بكسلية من أشكال (مستطيل، بيضوي، مضلع، فرشاة)
  gadgets.js   تعريف الأدوات — أداة جديدة = إضافة هنا + رسمتها في art.js
  world.js     البطاريق، الفيزياء، العملات، الفخاخ، الدخول والخروج
src/render/    الرسوم (كلها مرسومة بالكود، حادة بأي دقة)
src/levels/    المراحل
src/ui/        الواجهات، المحرر، الحفظ، الترجمة
src/audio.js   الموسيقى والمؤثرات (ضع mp3 في src/assets/music/<theme>.mp3 لتستبدل الموسيقى)
tools/sim.mjs  أداة فحص المراحل ورسم مسار البطاريق
```

الموسيقى: لكل منطقة اسم ملف — `menu`, `ice`, `jungle`, `desert`, `cave`, `night` (مثال: `src/assets/music/desert.mp3`).

الخط: Cairo (رخصة SIL OFL).
