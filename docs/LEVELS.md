# صيغة ملف المرحلة (JSON)

الشاشة منطقيًا **1920 × 960** بكسل. المحور `y` ينزل للأسفل. موقع البطريق والأدوات = **نقطة القدمين على الأرض**.

ملف الحزمة يكون بأحد الأشكال:
- مرحلة واحدة `{ ...level }`
- مصفوفة مراحل `[ {...}, {...} ]`
- حزمة باسم: `{ "name": { "ar": "...", "en": "..." }, "theme": "ice", "levels": [ ... ] }`

## الحقول

| الحقل | المعنى |
|---|---|
| `id` | معرّف فريد (نص) |
| `name`, `tip` | `{ "ar": "...", "en": "..." }` |
| `theme` | `ice` · `jungle` · `desert` · `cave` · `night` |
| `penguins` / `need` | عدد البطاريق / العدد المطلوب إنقاذه |
| `rate` | الفاصل بين خروج بطريق والثاني (1/60 ثانية) |
| `time` | الوقت بالثواني |
| `gadgets` | الأدوات المتاحة وعددها: `{ "cannon": 1, "spring": 2, "bridge": 1, "fan": 1, "turner": 1 }` |
| `shapes` | أشكال الأرض بالترتيب (اللاحق يغطي السابق) |
| `entry` | `{ "x", "y", "dir": 1 أو -1 }` مكان نزول البطاريق واتجاهها |
| `exit` | `{ "x", "y" }` باب الخروج (y = سطح الأرض) |
| `coins` | `[{ "x", "y" }]` |
| `hazards` | `[{ "t": "spikes", "x", "y", "w", "h" }]` — لمسها = خسارة البطريق |
| `decor` | زينة فقط: `pine iceRock sign palm bush statue vine cactus acacia rockPile crystal stalag banner lamp` مع `x, y, s` (الحجم) |
| `solution` | الحل (يستخدمه زر التلميح): `[{ "type", "x", "y", "rot", "power" }]` |
| `friend` | (اختياري) `{ "x", "y" }` يرسم الصديق ثلجي |
| `tutorial` | (اختياري) اسم أداة تُشرح قبل المرحلة |

## الأشكال

```json
{ "t": "rect", "x": 0, "y": 800, "w": 900, "h": 160, "mat": "ice", "r": 10 }
{ "t": "ellipse", "x": 600, "y": 700, "rx": 120, "ry": 60, "mat": "rock" }
{ "t": "poly", "pts": [[700,860],[1000,620],[1200,620],[1500,860]], "mat": "rock" }
{ "t": "stroke", "pts": [[100,500],[140,510]], "r": 20, "mat": "sand" }
{ "t": "rect", "x": 400, "y": 600, "w": 100, "h": 40, "erase": true }
```

المواد: `ice snow rock wood sand grass crystal metal`

## الأدوات وقيم rot / power

| الأداة | rot | ملاحظات |
|---|---|---|
| `cannon` | 0..8 = 30°,45°,60°,75°,90°,105°,120°,135°,150° (90 = للأعلى، أقل من 90 = يمين) | `power` 0..3 |
| `spring` | 0 | يقفز ~260 بكسل |
| `bridge` | 0..4 = -30°,-15°,0°,15°,30° | طوله 190، y = مركز اللوح (ضع y = سطح الأرض + 8) |
| `fan` | 0 | يرفع حتى ~330 بكسل ويحمي من السقوط |
| `turner` | 0 = يمين، 1 = يسار | |

## قواعد مفيدة

- البطريق يصعد درجة حتى **9 بكسل**؛ أعلى من هذا يعتبرها جدار ويرجع.
- السقوط أكثر من **430 بكسل** يقتل البطريق (إلا إذا مر بمروحة).
- الخروج من أسفل الشاشة = خسارة.
- `npm test` يفحص كل الملفات في `levels/` أيضاً: لازم تنحل بالحل، وما تنحل بدون أدوات، وكل العملات توصلها.
- `node tools/sim.mjs <id> --png` يرسم مسار البطاريق لتعديل المرحلة.
